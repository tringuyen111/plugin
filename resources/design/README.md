# Design

Design owns user experience and visual contracts. It does not own Product
priority, business-rule authority, technical architecture, implementation, or
QA verdicts.

## User-invoked

- **[design-experience](../../skills/design-experience/SKILL.md)** — Turn approved behavior into journeys, states, user flow, and wireframes before visual or technical implementation.
- **[design-visual](../../skills/design-visual/SKILL.md)** — Turn approved UX into an approved visual contract and optional Figma artifact.
- **[review-visual](../../skills/review-visual/SKILL.md)** — Orchestrate a fixed-point Design review, evidence acquisition, prioritized feedback, correction handoff, and re-review targets.
- **[creative-production](../../skills/creative-production/SKILL.md)** — Create source-backed direction for logos, identity, icons, banners, social visuals, and slide visual direction, with host-native generation only when available.

## Model-invoked

- **[user-flow](../../skills/user-flow/SKILL.md)** — Define user steps, decisions, navigation, states, and recovery without choosing visual style.
- **[wireframe](../../skills/wireframe/SKILL.md)** — Define layout and information hierarchy for one state and device assumption without pretending to be polished visual design.
- **[visual-contract](../../skills/visual-contract/SKILL.md)** — Define portable hierarchy, typography, spacing, density, components, responsive intent, accessibility, and parity characteristics.
- **[visual-review](../../skills/visual-review/SKILL.md)** — Apply reusable Design judgment to an already fixed artifact/evidence set inside `review-visual`.
- **[design-intelligence](../../skills/design-intelligence/SKILL.md)** — Retrieve deterministic local UI/UX/stack evidence for Design, Frontend, Review, and Creative owners without taking decision authority.
- **Figma provider adapter** — Internal adapter at `../../adapters/figma`; selected through `design.*` capabilities, not routed as a child skill.
