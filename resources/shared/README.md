# Shared

Shared cross-domain capabilities and primitives provide reusable evidence, context,
discipline, or deterministic adapters without taking Product, BA, Design,
Engineering, QA, Documentation, or Operations decision ownership.

## Model-invoked

- **[research](../../skills/research/SKILL.md)** — Collect or verify new decision-relevant evidence with source authority, provenance, contradiction handling, and truthful incompleteness without taking the downstream decision.
- **[domain-modeling](../../skills/domain-modeling/SKILL.md)** — Sharpen cross-domain terminology, entities, relationships, invariants, and accepted decision context; update only an authorized glossary or qualifying decision artifact.
- **[visual-capture](../../skills/visual-capture/SKILL.md)** — Capture state-aware visual evidence with provenance, PII masking, annotations, and a machine-readable manifest.
- **[capability-resolver](../../skills/capability-resolver/SKILL.md)** — Resolve provider-neutral capabilities against project profile, live tools, authority, and fallback without taking domain ownership.
