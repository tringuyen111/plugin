# System Plane

Explicit user-invoked workflows for maintaining and extending SDLC Intelligence. These skills do not participate in project-delivery routing.

- **[upgrade-sdlc-intelligence](../../skills/upgrade-sdlc-intelligence/SKILL.md)** — Route reusable skill-system maintenance to one lifecycle owner.
- **[create-skill](../../skills/create-skill/SKILL.md)** — Discover whether a capability deserves a Skill, shape one living design dossier, resolve ecosystem/provider boundaries, then materialize an approved provider projection.
- **[audit-sdlc-artifact](../../skills/audit-sdlc-artifact/SKILL.md)** — Audit context, depth, ownership, composition, portability, safety, and lifecycle fitness.
- **[qualify-sdlc-capability](../../skills/qualify-sdlc-capability/SKILL.md)** — Create and review invariant-based behavioral evidence.
- **[create-integration](../../skills/create-integration/SKILL.md)** — Map providers and MCP capabilities without taking domain ownership.
- **[create-domain-pack](../../skills/create-domain-pack/SKILL.md)** — Design a reusable domain pack that composes with the Delivery Plane.
- **[manage-skill-lifecycle](../../skills/manage-skill-lifecycle/SKILL.md)** — Govern promotion, monitoring, revision, deprecation, migration, and removal.

## Repository execution support

When these skills are used to maintain this repository, load
[`REPOSITORY-EXECUTION-MAP.md`](references/REPOSITORY-EXECUTION-MAP.md). It
connects lifecycle decisions to canonical validators, behavioral evidence
locations, release packaging, and the optional advanced-assurance branch.
