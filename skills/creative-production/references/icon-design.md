# Icon Design

Use the local icon style taxonomy for art direction and Codex host-native generation for final assets.

## Styles
Outlined, filled, duotone, thin, bold, rounded, sharp, flat, gradient, glass-like, pixel, hand-drawn, isometric, glyph, and animated-ready.

## Contract
- Prefer `currentColor` for UI icons unless the design system requires a semantic token.
- Use a consistent viewBox, stroke system, corner treatment, and optical weight across an icon family.
- Include an accessible name when an icon conveys meaning; decorative icons are hidden from assistive technology.
- Test clarity at compact and large sizes.
- Do not embed fonts or raster images in UI SVG icons.

Final generation must use the host-native creative capability. If unavailable, report UNAVAILABLE instead of switching providers.
