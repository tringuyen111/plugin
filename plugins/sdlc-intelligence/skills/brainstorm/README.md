Brainstorm is a deep pre-canonical idea-shaping Skill for turning rough ideas into a single living Markdown artifact: clarified flows, rules, decisions, risks, wording, and open questions before evidence-grounded Product judgment or downstream canonicalization.

## Design signature

**Explore deeply → clarify precisely → decide traceably → keep one living truth.**

- Deep, section-by-section elicitation instead of question dumping.
- One living Markdown artifact per idea.
- Adaptive output language without sacrificing technical precision.
- Stable `OQ-n` and material `DEC-n` traceability.
- Explicit interruption, concurrency, state, limits, and wording elicitation when complexity warrants it.
- Brainstorm detects downstream impact but does not seize PRD/URD/BRD/SRS authority.
