<h1 align="center">Brainstorm</h1>
<p align="center"><strong>Meaningful by Design.</strong></p>

Brainstorm is a standalone pre-canonical idea-shaping Skill for turning raw or still-fluid ideas into coherent idea truth: frame the real question, explore materially different possibilities, deepen consequential behavior and uncertainty, discriminate with evidence/constraints/judgment, then converge without claiming downstream authority. Conversation is a valid working surface; durable Markdown/files are optional representations when requested or project-native.

## Design signature

**Frame clearly → diverge materially → deepen selectively → discriminate honestly → converge proportionally.**

- Standalone exploration: no sibling Skill is required for Brainstorm to perform its own job.
- Anti-fixation divergence: generate materially different possibilities only while the decision space is genuinely open.
- Adaptive seven-lens deepening: ask only decision-changing gaps and re-route as the idea changes.
- Evidence/constraint/judgment discrimination before convergence; fixed truth is never "brainstormed" into alternatives.
- Conversation-first operation with optional durable one-current-truth persistence when requested or project-native.
- Stable `OQ-n` and material `DEC-n` traceability when durable or cross-section reference is useful.
- Brainstorm detects downstream ownership/evidence needs but does not seize Product/BA/Design/Architecture/Engineering authority.
