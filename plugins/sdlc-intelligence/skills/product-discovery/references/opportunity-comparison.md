# Opportunity Comparison

Use this module only when two or more already-bounded opportunities or segment variants must be compared for the current Discovery recommendation. Return dominance/trade-off/tie, sensitivity, and the exact evidence or authorized weight that would change the ordering.

## Compare only evidence-backed dimensions

Use dimensions material to the current Product decision, such as:

- user/problem consequence;
- affected segment/situation;
- strategic relevance when actually evidenced/authorized;
- evidence strength and transferability;
- riskiest unresolved assumption;
- cost/time to obtain decision-changing evidence;
- time sensitivity or reversibility when actually known.

Do not invent weights, market sizes, numeric scores, or composite precision to force a ranking.

## Choose the disposition shape

| Evidence shape | Return |
|---|---|
| one option is no worse on material known dimensions and clearly stronger on at least one | **dominance** |
| dimensions conflict | **qualitative trade-off** |
| difference depends on unknown/unauthorized weight | **tie / unresolved** |
| one evidence item or owner weight would flip the order | **sensitivity statement** naming that exact discriminator |

Learning cost is separate from opportunity value. A cheap-to-study problem is not automatically a better opportunity.

When an accountable Product owner must supply a strategic weight, expose the sensitivity and ask only that bounded input when appropriate. Do not manufacture the weight or require a specific interview Skill.

## Failure / correction

| Failure | Correction |
|---|---|
| numeric score uses guessed weights | remove fake precision; expose trade-off/sensitivity |
| one strong segment is averaged away | compare segment-specific opportunity truth instead of generic wording |
| evidence strength and opportunity value are conflated | separate evidence confidence from problem consequence/value |
| portfolio priority is invented to park/reject | preserve Discovery comparison and leave portfolio authority unresolved/downstream |

## Return contract

Return:

```text
dominance / trade-off / tie disposition
material dimensions supporting it
sensitivity: evidence or authorized weight that would change it
remaining uncertainty / next learning discriminator
```

Do not authorize Product priority, capability scope, packaging, or roadmap commitment.
