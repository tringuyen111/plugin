# Commercial Viability

Use this module only when **commercial treatment can change Product scope, priority, or viability**. It does not own pricing approval, billing architecture, legal terms, or invented willingness-to-pay truth.

Ask only what changes the Product decision:

- Is the capability required for core value realization or mainly expansion/segment-specific value?
- Which evidenced segment needs it?
- Is there a natural upgrade/growth trigger, or would gating block activation/value realization?
- Does usage/cost-to-serve materially threaten margin or sustainable delivery?
- Could entitlement/package treatment create unfairness, bill shock, churn, or support burden that changes scope/priority?

Possible Product-level hypotheses include `INCLUDE`, `TIER_FENCE`, `USAGE_LIMIT`, `ADD_ON`, `SEPARATE_OFFER`, or `UNRESOLVED` only when the distinction helps the decision.

Never fabricate exact willingness-to-pay evidence, price points, discounts, plan names, arbitrary feature fences, billing/metering implementation, legal/contract terms, pricing experiment results, or commercial approval authority.

Product topology and commercial packaging are different relations. A capability cluster may be packaged in several ways; unrelated capabilities may be sold together for commercial reasons.

## Failure / correction

- core value is gated only because a feature is `useful` -> return a value-realization viability risk.
- a distinct segment need is used to invent tier/price truth -> keep a segment/package hypothesis and unresolved commercial evidence/authority.
- cost-to-serve matters but Product chooses billing mechanics -> return the viability constraint; billing design stays downstream/with commercial/technical owners.
- package label drives Product topology -> return to capability-scope job/value relation.

## Return contract

Return only:

```text
viability risk / commercial hypothesis
evidenced segment + core-vs-expansion relation when material
scope / priority consequence
cost-to-serve / fairness / churn / support constraint when material
unresolved evidence / commercial owner or authority need
```
