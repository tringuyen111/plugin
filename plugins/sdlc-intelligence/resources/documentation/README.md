# Documentation

Documentation explains behavior that is already supportable from approved artifacts and current runtime evidence. It does not invent Product behavior, replace QA, hide defects, or redefine Design.

## User-invoked

- **[user-guide](../../skills/user-guide/SKILL.md)** — Turn verified or explicitly preview behavior into a task-oriented manual with reviewed structure, source traceability, and current visual evidence.

## Model-invoked

- **[manual-review](../../skills/manual-review/SKILL.md)** — Review a User Guide outline or page set for source coverage, task orientation, content-type separation, standalone readability, and stale or unsupported claims.
