# Creative Direction Model

Use when collateral direction is not already fixed by authoritative constraints.

```text
purpose/audience/message/brand/context
        -> hard constraints + success criteria
        -> materially different direction hypotheses
        -> same-criteria trade-off comparison
        -> target-context stress test
        -> highest-leverage refinement
        -> generation if requested/authorized
        -> inspected result vs frozen criteria
```

A direction is materially different only when a governing visual decision changes: focal strategy, composition, information density, type/image relationship, or brand expression. Color-only or ornament-only variants do not count.

## Target-context stress test

Check the dimensions that can invalidate the direction: target crop/safe zone, smallest realistic viewing size, long/short or localized copy, focal hierarchy, CTA/content competition, contrast/readability, brand distinctiveness, and production/export constraints.

## Re-entry

When the test fails, identify the causal lever first and refine it. When current platform/brand truth is missing and would change the direction, return to evidence acquisition instead of inventing a rule.
