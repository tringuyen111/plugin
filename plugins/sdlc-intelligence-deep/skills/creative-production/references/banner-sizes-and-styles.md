# Banner & Social Art-Direction Reference

## Authority boundary

Platform dimensions, safe zones, ad-format availability, UI chrome, and ad-policy/performance guidance change over time. Treat this file as an art-direction aid, **not** canonical platform policy. When the target platform materially constrains the asset, verify current authoritative requirements or use exact user/project-provided specs. Do not claim CTR superiority from a static size table.

Use aspect-ratio families such as square, portrait, vertical story, landscape, header/banner, and large-format print only as non-authoritative starting points. Choose the actual canvas from current target constraints.

## 22 Art Direction Styles

1. **Minimalist** — White space dominant, single focal element, 1-2 colors, clean sans-serif
2. **Bold Typography** — Type IS the design; oversized, expressive letterforms fill canvas
3. **Gradient / Color Wash** — Smooth transitions, mesh gradients, chromatic blends
4. **Photo-Based** — Full-bleed photography with text overlay; hero lifestyle imagery
5. **Illustrated / Hand-Drawn** — Custom illustrations, bespoke icons, artisan feel
6. **Geometric / Abstract** — Shapes, lines, grids as primary visual elements
7. **Retro / Vintage** — Distressed textures, muted palettes, serif type, halftone dots
8. **Glassmorphism** — Frosted glass panels, blur backdrop, subtle border glow
9. **3D / Sculptural** — Rendered objects, depth, shadows; product-centric
10. **Neon / Cyberpunk** — Dark backgrounds, glowing neon accents, high contrast
11. **Duotone** — Two-color photo treatment; bold brand color overlay on image
12. **Editorial / Magazine** — Grid-heavy layouts, pull quotes, journalistic composition
13. **Collage / Mixed Media** — Cut-paper textures, photo cutouts, layered elements
14. **Retro Futurism** — Space-age nostalgia, chrome, gradients, optimism
15. **Expressive / Anti-Design** — Chaotic layouts, mixed fonts, deliberate "wrong" composition
16. **Digi-Cute / Kawaii** — Rounded shapes, pastel gradients, pixel art, playful characters
17. **Tactile / Sensory** — Puffy/squishy textures, hyper-real materials, embossed feel
18. **Data / Infographic** — Stats front-and-center, charts, numbers as heroes
19. **Dark Mode / Moody** — Near-black backgrounds, rich jewel tones, high contrast
20. **Flat / Solid Color** — Single background color, clean icons, no gradients
21. **Nature / Organic** — Earthy tones, botanical motifs, sustainable brand feel
22. **Motion-Ready / Kinetic** — Designed for animation; layered elements, loopable

## Context-driven variables

- **Focal hierarchy:** what must be noticed first, second, and last for the target task.
- **Composition:** subject-led, type-led, product-led, data-led, or mixed; choose by message and available space.
- **Safe area/crop resilience:** test critical content against the verified target safe zone and representative crops.
- **CTA prominence:** balance action salience against message comprehension; position follows reading flow and context, not a fixed corner rule.
- **Typography:** choose size, line length, weight, and typeface count for viewing distance, language, brand, and density.
- **Content density:** restructure when copy competes with the focal idea; do not enforce one text ratio across all formats.
- **Contrast/accessibility:** satisfy applicable project/accessibility truth.
- **Print production:** use printer/project specs for bleed, color mode, DPI, and physical size.

## Direction comparison

Compare viable directions against the same criteria: message clarity, audience fit, brand distinctiveness, target-context legibility, crop resilience, production risk, and reuse/adaptation cost. Refine the highest-leverage weakness, then re-test.
