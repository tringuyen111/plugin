# Icon / Iconography Direction Method

Use this reference for **standalone, brand, campaign, documentation, or collateral iconography**. If the task defines Product UI icon semantics, system roles, interaction states, or component integration, return to the parent boundary with the unresolved Product UI semantics/system or implementation concern; host-native discovery owns any subsequent capability selection.

The bundled `data/icon/styles.csv` owns the style lookup taxonomy; this file owns family-coherence and visual-direction reasoning.

## Family invariants

Choose and keep explicit only the invariants material to the family:

- stroke vs fill logic and optical weight;
- corner/cap character (rounded, sharp, organic, geometric);
- silhouette complexity and negative-space discipline;
- perspective/dimensional convention when used;
- palette/duotone/gradient treatment when brand-relevant;
- target-size legibility and monochrome fallback;
- metaphor consistency across the requested icon set.

## Stress test

- Compare several icons side by side, not one isolated specimen.
- Test the smallest realistic delivery size and a larger display size.
- Check whether a detailed symbol collapses into noise or a thin family loses optical balance.
- Ensure meaning does not depend on color alone when the icon conveys information.
- Reject a style that is attractive in isolation but cannot scale coherently across the requested family.
