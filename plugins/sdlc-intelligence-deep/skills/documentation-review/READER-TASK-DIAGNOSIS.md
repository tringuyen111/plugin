# Reader-Task Diagnosis

```text
reader + job + prior knowledge + success condition
        -> simulate documented path
        -> first material failure
        -> causal scope
        -> correction lever
        -> affected-page set
        -> re-review evidence
```

| Cause scope | Typical reader failure | Preferred lever |
|---|---|---|
| prerequisite/context | cannot begin or misinterprets state/term | add or move concise prerequisite/context |
| content-type mix | must switch between learning, doing, lookup, and explanation mid-flow | split/reframe by reader need and cross-link |
| page structure | finds the page but cannot efficiently complete the task | reorder steps, expose decision point, move reference detail out of critical path |
| navigation/grouping | cannot locate the right page or duplicates create uncertainty | merge/split/reorder/group/cross-link by reader intent |
| evidence currency | screenshot/runtime behavior no longer proves the claim | refresh fixed-point evidence and re-inspect |
| unsupported/source conflict | documentation cannot truthfully choose behavior | narrow/remove claim or return to canonical owner |
| systemic repetition | many findings share one structural cause | fix the shared structure/template/navigation rule, then re-review affected pages |

Severity describes impact, not cause. A finding closes only after the named page/evidence is re-reviewed; a promised edit is not closure.
