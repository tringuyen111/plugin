## Cross-system findings retained

- Structural/package validity is a Gate 0 only; it does not prove decision quality or runtime activation.
- Capability boundaries should be narrow in accountability but deep in domain coverage. Adjacent hard cases remain locally understood when they can break the owned outcome.
- Shared vocabulary is not an ownership collision. Collision requires duplicated terminal accountability or conflicting doctrine.
- Native discovery owns capability selection. No Plugin-global router/ranker/active-Skill state is justified.
- Supporting capabilities may return bounded depth in-session without manufacturing Handoff artifacts or synthetic lifecycle state.
- The term **smallest** means smallest **complete** intervention/result, not happy-path minimalism.
- Critical invariants, decision rules, and heuristics should have distinguishable salience when forgetting one under context pressure changes correctness.
- Runtime native Skill invocation remains `NOT_OBSERVABLE` in this ChatGPT session; representative behavioral qualification remains `NOT_RUN` unless a real Skill/model runner executes frozen cases.
